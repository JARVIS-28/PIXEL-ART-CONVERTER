## 📝 Description

Pixel Art Converter is a desktop application that transforms regular images into stylized pixel art. With multiple pixelation styles and a user-friendly interface, you can easily create retro-styled pixel art from any image.

## ✨ Features

- **Multiple Pixelation Styles**: Choose from various pixelation effects:
  - Basic Pixelation
  - Color-Limited Pixelation
  - Mosaic Pixelation
  - ASCII Art Pixelation
  - Isometric Pixelation
  - Cartoon Pixelation
- **User-Friendly Interface**: Simple and intuitive design makes pixel art creation accessible to everyone
- **Live Preview**: See how your image looks with different styles before downloading
- **Custom Styling**: Retro-themed UI with pixel art aesthetics throughout the application
- **Download Support**: Save your pixel art creations to use in projects, games, or social media

## 🚀 Installation

### Prerequisites
- [Node.js](https://nodejs.org/) (v14 or later)
- [npm](https://www.npmjs.com/) (v6 or later)

### Steps
1. Clone this repository:
   ```
   git clone https://github.com/your-username/pixel-art-converter.git
   ```
2. Navigate to the project directory:
   ```
   cd pixel-art-converter
   ```
3. Install dependencies:
   ```
   npm install
   ```
4. Start the application:
   ```
   npm start
   ```

## 🛠️ Development

### Project Structure
- `index.html` - Main application HTML
- `main.js` - Electron main process file
- `renderer.js` - Application logic for the renderer process
- `preload.js` - Preload script for secure context bridging
- `styles.css` - Application styling
- `create-icon.js` - Script to generate the application icon

### Building
To build the application for your platform:
```
npm run make
```
